Termos de uso e privacidade

Última atualização: outubro de 2026

Resumo: o presentinho só monta a página da lista e gera o código Pix. Nós não recebemos, não guardamos e não repassamos dinheiro. Também não guardamos os dados da sua lista em servidor: eles ficam dentro do próprio link.

1. O que o presentinho faz

O presentinho é uma ferramenta gratuita para criar uma página de lista de presentes. Para cada presente, a página gera um código Pix estático (QR Code e Pix Copia e Cola) com a chave Pix e o valor que quem criou a lista informou. O pagamento acontece no aplicativo do banco de quem paga, direto para a conta dona da chave.

2. O que o presentinho não faz

  • Não é banco, instituição de pagamento nem intermediário. Não temos acesso a nenhum valor pago.
  • Não confirma pagamentos. Quem recebe confere no extrato do próprio banco.
  • Não estorna nem devolve pagamentos. Pedidos de devolução são tratados entre quem pagou e quem recebeu, ou com o banco de cada um.

3. Responsabilidade de quem cria a lista

Quem cria a lista é responsável por informar uma chave Pix e um nome de titular verdadeiros, que sejam seus ou que tenha autorização para usar. É proibido usar o presentinho para se passar por outra pessoa, pedir dinheiro de forma enganosa ou para qualquer atividade ilegal.

4. Cuidados de quem paga

Antes de confirmar qualquer Pix, confira no aplicativo do seu banco o nome de quem vai receber. Se o nome for diferente do esperado, não pague e avise quem te mandou o link. Só pague listas de pessoas que você conhece.

5. Privacidade e dados pessoais

  • Dados da lista: nome do evento, mensagem, nome do titular, cidade, chave Pix, WhatsApp e presentes ficam codificados dentro do link que você compartilha. Qualquer pessoa com o link consegue ver essas informações, por isso compartilhe só com quem você quer.
  • Rascunho: enquanto você monta a lista, um rascunho fica salvo apenas no seu navegador (armazenamento local). Ele não é enviado para nós.
  • Servidor: não temos banco de dados de listas. A hospedagem do site pode registrar dados técnicos de acesso, como endereço IP e navegador, para segurança e funcionamento.
  • Terceiros: as fontes do site são carregadas do Google Fonts. Os botões de WhatsApp abrem o WhatsApp com uma mensagem pronta; nada é enviado sem você confirmar.

Você pode apagar o rascunho limpando os dados do site no seu navegador. Como não guardamos as listas, não há cadastro para excluir.

6. Disponibilidade

O serviço é oferecido como está, sem garantia de funcionamento contínuo. Podemos mudar ou encerrar o serviço a qualquer momento. Links já criados podem deixar de funcionar se o site sair do ar.

7. Mudanças nestes termos

Podemos atualizar estes termos. A data no topo da página mostra a versão em vigor.
